# Steppe & Steam

Customized catalog project for Lesson 4: Flexbox and CSS Grid Layout.

## Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

The page includes a Flexbox header and shop layout, a responsive CSS Grid
catalog, 10 TypeScript products rendered with `map`, and a Flexbox statistics
section.
