# Alimzhan Galymzhan Student Portfolio

Lesson 3 project for practicing the CSS box model, typography, color formats,
visual hierarchy, and CSS variables with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Practice exercise additions

- A fourth project card
- A `--color-danger` CSS variable and a “Currently Learning” pill
- Updated `--spacing-section`
- A quote section below the hero
- Project-card padding converted from `rem` to `px`
- A hover state that lifts project cards
